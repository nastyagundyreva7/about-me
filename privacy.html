RUD COINS

Соглашение и обработка данных

Эта страница описывает, какие данные запрашивает прототип RUD Coins и для чего они используются.

Какие данные используются

При регистрации запрашиваются фамилия, имя, отчество (если есть), учебная группа и почта РУДН. Эти данные необходимы для создания профиля студента, регистрации на мероприятия и ведения истории начисления и списания RUD Coins.

Для чего используются данные

Данные используются в рамках работы программы RUD Coins: идентификация участника, учёт регистраций, подтверждение участия, начисление коинов и оформление обмена на доступные привилегии.

Согласие

Регистрация возможна только после подтверждения согласия пользователя на обработку предоставленных данных в рамках работы сервиса.

Cookies

Сайт использует технические cookies или аналогичные механизмы хранения в браузере для сохранения пользовательских настроек, в том числе факта принятия уведомления о cookies. В текущем прототипе данные профиля и состояние кошелька также сохраняются локально в браузере.

Безопасность

Публичный прототип на GitHub Pages не должен использоваться для хранения реальных паролей или чувствительных персональных данных. Для запуска полноценного сервиса необходимо подключить защищённый сервер, базу данных, хеширование паролей, серверную авторизацию и разграничение прав администратора.
