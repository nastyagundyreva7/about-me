RUD COINS

Соглашение и обработка данных

Эта страница описывает данные, которые используются для работы RUD Coins.

Какие данные используются

При регистрации запрашиваются фамилия, имя, отчество (если есть), учебная группа и почта РУДН. Также Supabase Auth обрабатывает учётные данные, необходимые для входа в аккаунт.

Для чего используются данные

Данные используются для идентификации участника, регистрации на мероприятия, подтверждения фактического участия, начисления и списания RUD Coins, а также обработки заявок на получение привилегий.

Согласие

Регистрация возможна после подтверждения согласия на обработку предоставленных данных в рамках работы сервиса. Не предоставляйте через сайт данные, которые не нужны для программы.

Cookies и локальное хранение

Сайт использует технические механизмы хранения в браузере, в том числе для сохранения факта принятия уведомления о cookies и корректной работы сессии. Данные аккаунта и записи программы хранятся в подключённой базе Supabase, а не в пароле или исходном коде сайта.

Безопасность

Пароли обрабатываются системой Supabase Auth и не должны записываться в код сайта. Публичный ключ Supabase предназначен для клиентского приложения; секретные ключи не должны публиковаться. Доступ к административным операциям ограничивается ролью admin и правилами RLS.

Контакт

Вопросы по программе и обработке данных следует направлять ответственному администратору проекта.
